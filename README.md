# Khbich — Android app downloads

This repository only holds the signed Android builds (APK) of the **Khbich ENSTTIC** app.
It contains no source code.

**Download the app from [khbich.com/app](https://khbich.com/app).**

The latest APK is always at:
https://github.com/joeyfrontend/khbich-releases/releases/latest/download/khbich.apk

Releases are published automatically by the app's build pipeline. Do not upload files here by hand.
